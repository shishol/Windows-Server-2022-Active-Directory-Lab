# File Services

## Overview

This section documents the implementation of enterprise file services within the Windows Server lab environment.

The configuration focuses on securing shared resources, implementing distributed file services, monitoring file access, and managing storage through Windows Server File Services and File Server Resource Manager (FSRM).

## Topics Covered

### NTFS Permissions

Configured and validated NTFS permissions to implement secure, role-based access to shared resources.

### File Auditing

Configured auditing policies to monitor successful and failed file access through Windows Security logs.

### SMB and NFS

Configured SMB and NFS shared folders to support file sharing and cross-platform resource access.

### DFS Namespaces

Implemented a domain-based DFS Namespace to provide users with a centralized and consistent path to shared resources.

### DFS Replication

Configured replication between file servers to improve availability and maintain synchronized copies of shared data.

### File Server Resource Manager

Configured storage quotas and file screening policies to manage disk usage and enforce organizational storage policies.
