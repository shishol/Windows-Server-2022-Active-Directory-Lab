# Active Directory

## Overview

This section documents the deployment and administration of Active Directory Domain Services (AD DS) within the lab environment.

The exercises focused on building and managing an enterprise Active Directory infrastructure, including identity management, domain configuration, forest trusts, replication topology, and authentication services.
